# 🩺 Multiple Disease Prediction System (Streamlit App)

This is a **Streamlit web application** that can predict the likelihood of multiple diseases based on user input.  
The models are trained using **Machine Learning algorithms** on publicly available datasets.  

## 🚀 Features
- 🧮 Predicts the risk of multiple diseases:
  - Diabetes
  - Heart Disease
  - Parkinson’s Disease
- 🌐 Easy-to-use **Streamlit web interface**
- ⚡ Real-time predictions
- 📊 Uses pre-trained ML models for accurate results
